# Nawa Music — المرحلة الثالثة (Flutter Audio Player)

## ما الذي يحتويه المشروع؟
- واجهة مشغل عربية داكنة.
- تشغيل/إيقاف، التالي/السابق.
- شريط تقدم وتقديم/ترجيع.
- التحكم بالصوت وسرعة التشغيل.
- قائمة تجريبية من 3 روابط صوتية عامة.
- `just_audio` لتشغيل الصوت و`audio_session` لإعداد جلسة الصوت.
- GitHub Actions لبناء APK تلقائياً حتى لو كنت تعمل من الهاتف فقط.

## مهم جداً
هذا مشروع بداية لتجربة مشغل الصوت، وليس تطبيق Spotify كاملاً. لا يحتوي بعد على:
- تشغيل بالخلفية مع إشعار وتحكم من شاشة القفل.
- تنزيل أوفلاين وتخزين تنبؤي.
- EQ مكاني أو تحليل ضوضاء.
- ربط API المصادقة أو NestJS.
- Stem splitting أو ريمكسات AI.

## أسهل طريقة لك من الهاتف فقط

1. حمّل ZIP وفك ضغطه إن أمكن.
2. افتح GitHub في متصفح الهاتف وسجّل الدخول.
3. أنشئ مستودعاً جديداً باسم `nawa-music-flutter`.
4. ارفع محتويات هذا المجلد إلى المستودع بحيث يكون `pubspec.yaml` في الجذر و`lib/main.dart` داخله.
5. افتح تبويب **Actions** في المستودع.
6. اختر **Build Android APK** ثم **Run workflow** (أو انتظر البناء بعد رفع الملفات).
7. بعد نجاح العملية افتح نتيجة التشغيل، ثم قسم **Artifacts** وحمّل `nawa-music-release-apk`.
8. فك ضغط ملف Artifact لتحصل على `app-release.apk`، ثم ثبّته على هاتف Android.

## إذا ظهر خطأ
أرسل صورة صفحة Actions التي تظهر الخطأ، وسأحدد لك ما يجب إصلاحه. لا ترسل كلمات المرور أو مفاتيح API.

## التشغيل محلياً (إذا توفر كمبيوتر عليه Flutter)
```bash
flutter pub get
flutter run
```

## تعديل روابط الأغاني
افتح `lib/main.dart` وابحث عن `SoundHelix Song`. استبدل `url` برابط ملف صوتي مباشر تملك حق استخدامه. الرابط يجب أن يسمح بطلبات HTTP من التطبيق.
